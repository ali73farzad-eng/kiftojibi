کیف تو جیبی علیرضا – نسخه اندروید ۱.۳.۰

این یک پروژه کامل Android Studio است که فایل اصلی HTML نسخه ۱.۳.۰ شما را داخل WebView آفلاین اجرا می‌کند.
- رابط فارسی و امکانات HTML نسخه ۱.۳.۰ همراه پروژه است.
- اطلاعات برنامه در localStorage داخلی WebView ذخیره می‌شود.
- نام کاربری و رمز در SharedPreferences اندروید با PBKDF2 ذخیره می‌شود.
- برای اولین اجرا باید یک حساب جدید بسازید؛ حساب ویندوز به گوشی منتقل نمی‌شود.
- انتقال داده‌ها بین ویندوز و گوشی از طریق فایل پشتیبان JSON داخل برنامه انجام می‌شود.

ساخت APK:
1) در Android Studio پروژه این پوشه را باز کنید.
2) اجازه دهید Gradle Sync انجام شود (نیازمند دریافت Gradle و Android SDK است).
3) از Build > Build Bundle(s) / APK(s) > Build APK(s) استفاده کنید.
4) خروجی debug در app/build/outputs/apk/debug/app-debug.apk قرار می‌گیرد.

توجه: این بسته APK کامپایل‌شده نیست؛ سورس پروژه اندروید است. در این محیط Android SDK/Gradle برای تولید و تست APK در دسترس نبود. قبل از استفاده واقعی، از اطلاعات پشتیبان بگیرید.
